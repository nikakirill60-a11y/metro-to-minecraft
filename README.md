# OBJ Models — Minecraft Forge 1.12.2

Мод загружает модели Wavefront OBJ из `config/obj` и позволяет размещать их в мире через отдельное меню предмета **Инструмент OBJ**.

## Установка / сборка

1. Требуется Java 8 и Forge MDK `1.12.2-14.23.5.2860` (Gradle ForgeGradle 2.3).
2. В корне проекта: `gradlew build` (или `gradle build`). Готовый jar появится в `build/libs/`.
3. Скопируйте jar в `mods`.

## Структура модели

```text
config/obj/
  my_house/
    model.obj
    texture.png
```

Каждая модель — отдельная папка. Имя папки показывается в меню. OBJ должен содержать `v`, `vt` и `f` (треугольные или полигональные грани); координаты UV читаются из `vt`. `texture.png` необязательна. Используйте текстуру PNG и указывайте её UV в OBJ. Материалы MTL пока не разбираются; текстура загружается из фиксированного `texture.png`.

В игре возьмите **Инструмент OBJ** из вкладки «Декорации», нажмите ПКМ, выберите модель, задайте поворот и нажмите «Поставить модель». Модель размещается перед игроком. Правый клик по модели направляет на неё прицел; сущность сохраняется в мире.

## Коллизия и ограничения

Коллизия реализована отдельной сущностью, не блоком, и вычисляется по габаритам OBJ (bounding box), а не по одному кубу блока. Это совместимо с физикой сущностей Minecraft, которая оперирует AABB: точная треугольная физическая коллизия движком 1.12.2 не поддерживается. Размеры визуализации нормализуются так, чтобы наибольший габарит был около одного блока; исходная форма и UV сохраняются. Модели должны быть разумного размера и иметь корректные грани.
